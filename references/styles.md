# 4 种画风

同一份 `storyboard.json`，改一个 `style` 字段就能换整套视觉。内容、时间轴、字幕位置完全不变。

选择依据是**受众期待**，不是个人审美：

| 受众/场景 | 推荐 |
|---|---|
| 信息流刷到的泛人群、家长、学生 | `flat-kids` |
| 机构号、专业读者、政策/科研解读 | `editorial` |
| 科技媒体、AI/芯片/数据主题、B站 | `dark-tech` |
| 人文、健康、心理、母婴 | `paper` |

---

## flat-kids — 扁平贴纸

最"卡通"的一套，也是唯一适合低龄受众的一套。

- 背景暖米色，大色块圆形装饰，无纹理
- 卡片：粗黑描边（4px）+ 硬阴影 + 大圆角（28px）
- 字幕：白底 + 粗黑边 + 硬阴影（贴纸感），数字染成朱红
- 转场：淡入
- 标题字体：黑体 900（最重）

| token | 值 |
|---|---|
| bg | `#FFF3E0` |
| paper | `#FFFCF4` |
| ink | `#241C15` |
| muted | `#8A7461` |
| accent | `#F0562D` 朱红 |
| accent2 | `#1E8E7E` 墨绿 |
| pop | `#FFC94D` 明黄 |
| line | `#241C15` |

**适合**：为什么天是蓝的、为什么猫爱纸箱、刷牙要刷几分钟。

## editorial — 杂志信息图

最"不卡通"、最克制的一套。给机构、专业读者看，或需要显得可信时用。

- 背景米白（`#F6F4EF`），叠加极淡纸纹
- 卡片：无粗边、小圆角（3px）、细腻投影，像印刷品
- 标题用**衬线**（Noto Serif SC），正文黑体，形成杂志式对比
- 字幕：白底 + 左侧砖红色竖线（引文块），带轻微投影
- 转场：横向擦除（wipe）
- 装饰：左上角短线、右下角 `01 / 05` 页码

|---|---|
| bg | `#F6F4EF` |
| paper | `#FFFFFF` |
| ink | `#16181D` |
| muted | `#6B6F76` |
| accent | `#C0432B` 砖红 |
| accent2 | `#1F4E5F` 深蓝绿 |
| pop | `#E2BE6B` 旧金 |
| line | `#D8D4CA` |

**适合**：政策解读、行业报告、科研进展、ESG/合规说明、书评。

## dark-tech — 深色科技

屏幕感最强，适合信息流里"一眼像科技内容"。

- 背景近黑（`#0B0E13`），44px 网格线 + 双色光晕
- 卡片：细线框（1px）+ 青色外发光
- 字幕：半透明暗底 + 左侧青色竖线，**等宽字体**
- 转场：横向推入（push）
- 装饰：青/蓝双色径向光斑

| token | 值 |
|---|---|
| bg | `#0B0E13` |
| paper | `#141922` |
| ink | `#E8ECF2` |
| muted | `#8A94A6` |
| accent | `#35E0C0` 青 |
| accent2 | `#6C8CFF` 蓝紫 |
| pop | `#FFD166` 琥珀 |
| line | `#242C3A` |

**适合**：AI 模型原理、芯片制程、算法、数据安全、卫星/航天。

**注意**：深色底在手机户外强光下对比度低，字号要比浅色风格更大一点（模板已按 `U` 统一放大，字幕仍建议 ≤12 字）。

## paper — 手账笔记

温和、有人味，适合"讲给自己听"的语气。

- 背景米黄（`#FBF7EC`）+ 细横线纸纹
- 卡片：细线框（2px）+ 轻微旋转（-0.6°）+ 淡阴影，像贴在纸上
- 标题用**楷体**，正文楷体
- 字幕：明黄色马克笔底（半透明横条）
- 装饰：左上/右下两片"胶带"
- 进度条：顶部虚线（手绘感）

## 微调色板

不想换整套风格、只想换主色时，在 storyboard 里加：

```json
"themeOverride": {"accent": "#2F6F4E", "pop": "#F2C14E"}
```

支持 8 个键：`bg paper ink muted accent accent2 pop line`，值必须是 `#RRGGBB`（3 位简写会被忽略）。

**优先级**：`themeOverride` > 预设。只改 `accent` 与 `pop` 最安全；改 `bg` 要连带看 `ink` 的对比度。

## 字体依赖

模板不打包字体，直接用系统字体栈：

- 黑体：`Noto Sans SC` → `Source Han Sans SC` → `Microsoft YaHei` → `PingFang SC`
- 衬线：`Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → `SimSun`
- 楷体：`Kaiti SC` → `KaiTi` → `STKaiti`
- 等宽：`JetBrains Mono` → `Cascadia Mono` → `Consolas`

Windows 自带雅黑/宋体/楷体，macOS 自带苹方/宋体/楷体，都有兜底，不会掉字。
