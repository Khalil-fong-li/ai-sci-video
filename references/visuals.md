# 8 种画面类型

每场只选一种。选型的判断标准：**这一句口播最需要观众"看到"什么**。

| 想让人看到 | 用 |
|---|---|
| 一个真实场景/物件 | `image` |
| 几个概念词 | `keywords` |
| 一个数字的份量 | `stat` |
| 谁大谁小 | `bars` |
| 事情怎么发生的 | `steps` |
| 两种东西的差别 | `compare` |
| 一句话本身 | `quote` |
| 停顿 | `blank` |

---

## image — 一张图 + 运镜

```json
{"type": "image", "src": "images/s1.png", "motion": "push-in", "fit": "cover", "label": "图注（可选）"}
```

| 字段 | 说明 |
|---|---|
| `src` | 相对 `public/` 的路径，如 `images/s1.png` |
| `motion` | `push-in` 缓推 / `pull-out` 缓拉 / `pan-left` `pan-right` 横移 / `tilt-up` `tilt-down` 纵移 / `still` |
| `fit` | `cover` 铺满裁切（默认）/ `contain` 完整显示 |
| `label` | 图片下方等宽小字图注，只在竖屏显示 |

**用它的场合**：实物、场景、人物、需要"这就是它"的实感。AI 配图 prompt 见 `image-prompts.md`。

**注意**：竖屏时图片只占上部约 61% 高度，主体要放在画面中上部；横屏全屏铺满，主体居中即可。

## keywords — 关键词砸下来

```json
{"type": "keywords", "words": ["舷窗", "为什么是圆的"], "note": "看着理所当然"}
```

1–5 个词，逐条弹入，每条带强调色下划线（`paper` 画风是马克笔色块）。1 个词字号最大（约 168px），5 个词最小（约 62px）。

**用它的场合**：开场抛概念、拆解名词、一句话里有两个对立词（"直觉 / 真相"）。

**注意**：每个词 ≤12 字，否则换行难看。`note` 是补充小字，写一句转折更好（"但最早不是"）。

---

## stat — 一个大数字

```json
{"type": "stat", "value": "3", "unit": "倍", "label": "方窗四角的应力"}
```

`value` 里的数字会 count-up 滚动（支持小数，如 `"97.5"`；非数字部分原样保留，如 `"2–3"`）。

**用它的场合**：一个数字就能改变认知时。数字要比形容词有力。

**注意**：数字必须有出处。没有可靠来源就改成 `quote` 或 `keywords` 的定性表述，别编精确值博眼球。

---

## bars — 条形对比

```json
{"type": "bars", "unit": "倍", "max": 4, "items": [
  {"label": "圆窗边缘", "value": 1},
  {"label": "方窗四角", "value": 3}
]}
```

2–6 条，条长按 `max`（默认取最大值）比例生长，最后一条自动用强调色（用于"结论那一项"）。

**用它的场合**：比大小、排名、前后对比。把最后一条放"要强调的那个"。

---

## steps — 编号流程

```json
{"type": "steps", "title": "裂纹是这么来的", "items": [
  "机身增压鼓胀", "方角处应力集中", "反复起降后开裂"
]}
```

2–5 步，竖向排列，编号圆点 + 连线，第一步用强调色。

**用它的场合**：讲机制、讲因果链、讲操作顺序。`title` 是一句引导语，可省。

**注意**：每步 ≤14 字，写成"动词 + 结果"最清楚。

---

## compare — 左右对比

```json
{"type": "compare",
 "left":  {"title": "方窗", "points": ["五十年代的喷气客机", "两次空中解体"]},
 "right": {"title": "圆窗", "points": ["应力沿弧线分散", "再没出过同类事故"]}}
```

左栏用中性灰（现状/错误方案），右栏用强调色（新方案/正确解）。每栏 1–4 个要点。

**用它的场合**：前后、正误、方案 A/B。**右栏放你想让人记住的那个**。

---

## quote — 金句

```json
{"type": "quote", "text": "圆不是好看，是把力散开的最短路径。", "by": "结构力学常识"}
```

大字居中，带引号装饰，`by` 是小字署名/出处。

**用它的场合**：全片结论、反转、值得截图的一句。通常放最后一场，也常直接复用为片尾 `line1`。

**注意**：≤40 字。超过 60 字会挤到换行三行以上。

---

## blank — 空卡

```json
{"type": "blank"}
```

纯背景色，无内容。

**用它的场合**：极少。真要制造停顿，不如把上一场的 `gap` 调大。

---

## 排布模板

30 秒 5 场的常用骨架：

```
s1 keywords  抛概念/提问
s2 image     给实感（或 compare 给反差）
s3 steps     讲机制
s4 stat/bars 给数字
s5 quote     收结论
```

60 秒 7–8 场时，在 s2 后插一场 `compare`，在 s4 后插一场 `image` 换气。
